## Как это устроено

Статика без сборщика: HTML, один общий `style.css`, **никакого JavaScript на страницах**.

Каждая страница лежит в четырёх файлах — русский и английский, тёмная и светлая тема:

```
index.html            русский, тёмная
index.light.html      русский, светлая
index.en.html         английский, тёмная
index.en.light.html   английский, светлая
```

Тема задана именем файла, а не состоянием в браузере. Поэтому переключатель — обычная
ссылка, выбор нигде не хранится, и страница не может «помнить» чужую тему. Разделы без
светлой версии — Кодекс, скилл и Noise Dream — есть только в тёмной.

## Как править текст

Правьте **тёмный** файл, потом пересоберите:

```bash
node tools/variants.mjs
```

Из `index.html` получатся все четыре варианта. Светлые версии руками не трогают��
их перезапишет сборка. Год в подвале подставляется при сборке, так что надпись
не устареет сама.

Проверить, что все ссылки ведут куда надо:

```bash
node tools/verify-variants.mjs
```

## Локальный просмотр

```bash
node tools/serve.mjs
```

Откроется на `http://127.0.0.1:8099`. Сервер отдаёт `404.html` на неизвестный путь —
как это делает GitHub Pages.
